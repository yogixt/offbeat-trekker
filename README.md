# Offbeat Trekker

An earlier iteration of the [Offbeats](https://github.com/yogixt/offbeat1.2) travel app concept, with login/signup, a profile page, and a destinations browser.

**Live:** [offbeat-trekker.vercel.app](https://offbeat-trekker.vercel.app)

![Offbeat Trekker landing page](docs/screenshot.png)

## Stack

- React · TypeScript · Vite · shadcn/ui · Tailwind CSS
- Capacitor (Android packaging)

## Development

```bash
npm install
npm run dev
```
